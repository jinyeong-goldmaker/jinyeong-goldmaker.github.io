CNU Logic Lab

A practice tool for Chonnam National University students studying propositional logic and predicate logic.

Truth Table Generator

Generate truth tables for propositional formulas, classify them as tautologies, contradictions, or contingencies, and test argument validity.

WFF · Main Connective

Check whether a formula is well formed and identify its main connective. Both propositional and predicate logic are supported.

Natural Deduction Prover

Construct a proof line by line and verify each rule application, including Fitch-style subproofs.

Semantic Tableau

Expand a semantic tableau automatically to test validity or satisfiability and display a countermodel when available.

Tips

  • Use the symbol buttons or type formulas directly from the keyboard.
  • ~, ! → ¬  |  &, ^ → ∧  |  | → ∨
  • -> → →  |  <-> → ↔
  • forall x, (x) → ∀x  |  exists x, (?x) → ∃x
  • To avoid conflict with term letter v, type | or ∨ for disjunction.
  • In predicate logic, lowercase letters are treated as terms; a term is treated as a variable when bound by a quantifier and otherwise as a constant name.
