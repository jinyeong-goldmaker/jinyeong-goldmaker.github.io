전남대학교 논리학 실습도구

전남대학교 학생들이 문장논리(propositional logic)와 술어논리(predicate logic)를 함께 연습할 수 있는 실습도구입니다.

진리표 생성기

문장논리 문장을 입력하면 진리표를 자동으로 만들고, 항진·모순·우연 여부를 판정합니다. 여러 전제와 결론을 넣어 논증의 타당성도 검사할 수 있습니다.

적형식 · 주연결사 확인

입력한 문장이 올바른 적형식(WFF)인지 검사하고, 주연결사가 무엇인지 알려줍니다. 문장논리와 술어논리 모두 지원합니다.

자연연역 증명기

전제와 결론을 입력한 뒤, 한 줄씩 규칙을 적용해 증명을 작성하면 각 줄이 올바른지 즉시 검증해 줍니다. 가정을 이용한 하위증명(→I, ¬I, ∨E, ∃E 등)도 지원합니다.

진리나무

전제와 결론(또는 문장 하나)을 넣으면 진리나무(semantic tableau)를 자동으로 전개해 타당성/충족가능성을 판정하고, 무효인 경우 반례(모형)를 보여줍니다.

사용 팁

  • 화면의 논리기호 버튼을 눌러 입력하거나, 아래의 키보드 입력법을 사용할 수 있습니다.
  • 문장논리 기호 입력
    ~ 또는 ! 입력: ¬ (부정) & 또는 ^ 입력: ∧ (연언) | 입력: ∨ (선언) -> 입력: → (조건언) <-> 입력: ↔ (쌍조건언) \bot 입력: ⊥ (모순)
  • 술어논리 기호 입력
    forall x 또는 (x) 입력: ∀x (전칭양화) exists x 또는 (?x) 입력: ∃x (존재양화) != 입력: ≠ (부등)
  • 술어논리의 항 문자 v와 선언 기호가 혼동되지 않도록, 선언은 | 또는 화면의 ∨ 버튼을 사용하세요.
  • 술어논리에서 소문자는 모두 항(term)이며, 양화사에 의해 묶이면 해당 범위 안에서는 변항으로, 묶여 있지 않으면 상항(고정된 이름)으로 취급합니다.
