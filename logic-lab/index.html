기호논리학 실습도구

문장논리(propositional logic)와 술어논리(predicate logic)를 함께 연습할 수 있는 무료 웹 도구입니다. 논리학당의 진리표·적형식 확인 도구와 기호논리학 실습실의 자연연역 증명 검증기에서 영감을 받아, 두 도구의 장점을 한 곳에 모으고 진리나무(semantic tableau) 검사를 더했습니다.

진리표 생성기

문장논리 문장을 입력하면 진리표를 자동으로 만들고, 항진·모순·우연 여부를 판정합니다. 여러 전제와 결론을 넣어 논증의 타당성도 검사할 수 있습니다.

적형식·주연결사 확인

입력한 문장이 올바른 적형식(WFF)인지 검사하고, 주연결사가 무엇인지 알려줍니다. 문장논리와 술어논리 모두 지원합니다.

자연연역 증명기

전제와 결론을 입력한 뒤, 한 줄씩 규칙을 적용해 증명을 작성하면 각 줄이 올바른지 즉시 검증해 줍니다. 가정을 이용한 하위증명(→I, ¬I, ∨E, ∃E 등)도 지원합니다.

진리나무 (semantic tableau)

전제와 결론(또는 문장 하나)을 넣으면 진리나무를 자동으로 전개해 타당성/충족가능성을 판정하고, 무효인 경우 반례(모형)를 보여줍니다.

사용 팁

기호는 화면의 기호 버튼을 눌러 입력하거나, 키보드로 직접 입력할 수 있습니다. 예를 들어 ~, ! → ¬  |  &, ^ → ∧  |  | → ∨  |  -> → →  |  <-> → ↔  |  forall x, (x) → ∀x  |  exists x, (?x) → ∃x 로 자동 변환됩니다. (술어논리 항 문자 v와의 충돌을 피하기 위해 v는 ∨로 자동 변환되지 않습니다 — |나 ∨ 기호를 사용하세요.)

술어논리에서 소문자는 모두 항(term)입니다. 특정 문자가 변항인지 상항인지는 별도로 구분하지 않고, 양화사에 의해 묶여 있으면 그 범위 안에서는 변항으로, 묶여 있지 않으면 상항(고정된 이름)으로 취급합니다.
